# Deutsch Mit Mir — النسخة التجريبية

## التشغيل على الكمبيوتر
1. ثبّتي Python 3.10 أو أحدث.
2. افتحي Terminal داخل مجلد المشروع.
3. أنشئي بيئة افتراضية:
   - Windows: `py -m venv .venv` ثم `.venv\Scripts\activate`
   - Mac/Linux: `python3 -m venv .venv` ثم `source .venv/bin/activate`
4. ثبّتي المكتبات: `pip install -r requirements.txt`
5. انسخي `.env.example` إلى ملف اسمه `.env` وضعي مفتاح OpenAI API الخاص بك في `OPENAI_API_KEY`.
6. شغّلي:
   `python -m flask --app app run --debug`
7. افتحي الرابط الذي يظهر غالبًا: `http://127.0.0.1:5000`

## مهم
- تحتاجين مفتاح API منفصلًا، واستخدام الـAPI قد يترتب عليه تكلفة حسب الاستعمال. اشتراك ChatGPT لا يتضمن تلقائيًا رصيد API.
- لا تضعي مفتاح API في ملفات الواجهة أو تشاركيه مع أي شخص.
- النسخة الحالية تحفظ نص الـPDF وذاكرة المحادثة في ذاكرة الخادم مؤقتًا، وقد تُفقد عند إعادة تشغيله.
- يدعم استخراج النص من PDF. الملفات المصورة/الممسوحة ضوئيًا تحتاج OCR في إصدار لاحق.
- هذا نموذج أولي محلي لمستخدم واحد، وليس جاهزًا للنشر العام أو لحفظ حسابات متعددة.
- لتحسين ربط الإجابات بالمنهج في ملفات طويلة، نضيف لاحقًا تقسيم المستند إلى مقاطع والبحث الدلالي (RAG).
